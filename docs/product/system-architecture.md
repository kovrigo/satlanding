# Pencil In: устройство сайта

Прототип. Сайт статический: без сервера, без фреймворка, без автотестов. Проверка руками на тестовом сайте.

## Как устроен

- Обычные HTML, CSS и скрипты в папке `site/`. Без шага сборки: скрипты подключаются как модули браузера.
- `serve.ts` на Bun отдаёт `site/`, на `/health` отвечает номером коммита.
- Попытка живёт в localStorage браузера. Браузер не даёт сохранять: срез проходится без возврата, на экране предупреждение.
- Каждая страница несёт скрипт виджета ошибок для тестового сайта.

## Страницы

- `/`: лендинг по дизайну Ольги. Пример вопроса «Try one now», кнопки «Start the free test» ведут на `/test/`, форма листа ожидания.
- `/test/`: экран теста в стиле Bluebook. Начало, вопросы двух разделов, проверка перед сдачей, экран между разделами. Вид выбираем на этапе макетов.
- `/results/`: результат. Балл по разделам «примерно», домены, слабые места, разбор, лист ожидания, «пройти ещё раз». Без сданной попытки ведёт на `/test/`.

## Файлы

- `site/index.html`, `site/styles.css`: лендинг и его стили.
- `site/test/index.html`, `site/test/test.css`: экран теста.
- `site/results/index.html`: результат, в стилях лендинга.
- `site/js/questions.js`: 25 вопросов: раздел, домен, трудность, текст, варианты или свой ответ, верный ответ, объяснение.
- `site/js/attempt.js`: чтение и запись попытки в localStorage: ответы, отметки, зачёркивания, выделения, заметки, текущий вопрос, время начала раздела.
- `site/js/test.js`: экран теста: таймер, навигатор, отметки, зачёркивание, свой ответ, сдача раздела.
- `site/js/tools.js`: выделение и заметки, справочник формул, калькулятор.
- `site/js/score.js`: подсчёт: разделы, домены, слабые места, диапазон балла, разбор своего ответа.
- `site/js/results.js`: страница результата.
- `site/js/waitlist.js`: форма листа ожидания на лендинге и на результате.

## Правила

- Таймер считается от времени начала раздела в попытке: закрыть вкладку можно. Время вышло: введённый ответ засчитывается, раздел сдаётся сам.
- Две вкладки: работает последняя открытая, другая предлагает перейти к ней.
- Лист ожидания открывает письмо на hello@bagira.study с готовым текстом: имя, роль, класс. Под кнопкой видны адрес и текст для копирования. На экране результата добавляет в письмо итог среза.
- Кнопка «пройти ещё раз»: сбрасывает попытку и ведёт на начало среза.
- Цвета и шрифты лендинга и результата из дизайна Ольги, в CSS-переменных. Вид экрана теста решается на этапе макетов.
