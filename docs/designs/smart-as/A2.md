## Colours: tokens only

The page will be shown in three colour versions with the same character, so
every colour must come from CSS custom properties on `:root`, and nowhere
else: no hex, rgb or named colour outside `:root`, including inside inline
SVG (use `currentColor` or `var(--…)`). Use exactly these tokens:
- `--paper` page background, `--grid` graph-paper lines,
- `--ink` pen colour for headings, drawings and the character's lines,
- `--text` body text, `--muted` secondary text,
- `--surface` cards and notes,
- `--hl` highlighter (the one accent), `--hl-soft` a light tint of it
  (tape, light fills),
- `--on-ink` text on an `--ink` background.
Build this file with the blue version: `--paper:#FBFAF4`, `--grid` a faint
blue, `--ink:#1A2BD6`, `--text:#1C1F33`, `--hl:#FF3EA5`. Tints and
transparency may use `color-mix()` with the tokens.
