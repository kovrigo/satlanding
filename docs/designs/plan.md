# План: лендинг SAT со стартовым срезом

## Макет экрана теста

Выбран вариант A (Ольга, 2026-11-03): как настоящий экзамен. Файл: `docs/designs/test-screen-mockup.html`.

- Белый фон, почти чёрный текст, светло-серые разделители, пунктир под шапкой и над нижней панелью.
- Один синий акцент: кнопка Next, выбранный ответ.
- Шрифты: Inter для интерфейса, Source Serif 4 для текста задания.
- Экран теста строим из HTML этого макета. Лендинг остаётся по дизайну Ольги.

## Сборка

Прототип: без фреймворка, без сборки, без автотестов. Проверка руками и скриптом в браузере на тестовом сайте.

1. Лендинг `site/index.html` + `site/styles.css`: перенос дизайна Ольги один к одному. Убрать старый экран теста из дизайна. Кнопки «Start the free test» ведут на `/test/`. Пример «Try one now» работает на месте. Правки текстов:
   - FAQ «Will I get an SAT score?»: да, примерный диапазон по каждому разделу, с пометкой «approximately».
   - FAQ «Can I use a calculator?»: калькулятор и справочник формул встроены в тест.
   - Убрать «or switch the timer off» и «You can switch the timer off before you start».
   - Форма листа ожидания: mailto на hello@bagira.study, адрес и текст для копирования под кнопкой.
2. Вопросы: `site/js/questions.js` (готово).
3. Экран теста `site/test/index.html`, `site/test/test.css`, `site/js/test.js`, `site/js/tools.js`, `site/js/attempt.js` по макету A.
4. Подсчёт `site/js/score.js`, результат `site/results/index.html`, `site/js/results.js`, лист ожидания `site/js/waitlist.js`.
5. Тестовый сайт: `paneweb up`, ссылка на доске.

## Подсчёт балла

- Вес вопроса: лёгкий 1, средний 2, трудный 3.
- Доля = набранный вес / весь вес раздела.
- Середина балла = 200 + 600 × доля, округлить до 10. Диапазон: середина ± 40, в пределах 200–800.
- Слабые места: два домена с наименьшей долей верных; при равенстве слабее тот, где ошибка в более лёгком вопросе. Все верны: слабых мест нет.
