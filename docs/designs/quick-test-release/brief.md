# Быстрый тест на лендинге: Brief

Автор задачи: Ольга. Задача 297.

## Проблема

На лендинге Pencil In стоит срез из 25 вопросов на 35 минут. Это высокий порог: ученик, который просто зашёл посмотреть, вряд ли сразу сядет на 35 минут. Ольга хочет короткий лёгкий тест, который можно пройти за 5 минут.

## Для кого

- Ученик, который впервые пришёл на лендинг и хочет быстро понять свой уровень.
- Ученик или родитель, который записался в лист ожидания и получает полный тест в письме.

## Что есть сейчас

Один тест из 25 вопросов разной сложности, с оценкой 200–800 по разделам, разбором и формой листа ожидания. Дизайн экрана теста повторяет Bluebook.

## Что сделано

- На лендинге теперь быстрый тест: 10 лёгких вопросов, 5 по чтению и 5 по математике, 3 и 2 минуты.
- Темы покрывают все восемь доменов SAT. Один вопрос по математике с вводом числа.
- Результат быстрого теста: число верных ответов по разделам и по темам, слабые места, разбор каждого вопроса, форма листа ожидания. Оценки 200–800 нет: десять лёгких вопросов дают завышенный балл.
- Полный тест из 25 вопросов остаётся без изменений по отдельной ссылке, для писем после записи. На лендинге ссылки на него нет, поисковики его не видят.
- Результат полного теста показывает оценку, а вместо формы записи текст «Вы уже в листе ожидания».
- Ответы и результат каждого теста хранятся в браузере отдельно. Закрыл вкладку, вернулся, ответы на месте.
- Тексты лендинга обновлены под быстрый тест: число вопросов, время, темы, пример результата, вопросы и ответы.
- Дизайн не меняется.

## Варианты, которые отвергли

- Сократить 25 вопросов до 10 и удалить полный тест. Ольга хочет сохранить полный тест для писем.
- Показывать оценку 200–800 и в быстром тесте. Отказались: оценка по десяти лёгким вопросам вводит в заблуждение.

## Какие истории проекта поддерживает

- S1: ученик понимает из лендинга, сколько длится тест. Теперь 5 минут.
- S2: тест без регистрации и почты.
- S6: можно закрыть вкладку и вернуться.
- S7 и S9: результат по разделам, доменам и разбор.
- S8: ориентировочный балл теперь только в полном тесте.
- S10: следующий шаг и запись в лист ожидания.

## Вне задачи

- Отправка писем после записи. Ссылку на полный тест в письмо вставляет команда.
- Хранение результатов на сервере, регистрация, адаптивность.
- Новый дизайн.
